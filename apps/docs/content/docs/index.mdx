# Nostr Markets Development Kit

NMDK pins the protocol drafts, Nostr runtime, Cashu and EVM payment drivers,
contract artifacts, application, and local integration stacks that form one
reviewable marketplace snapshot.

Start with [Getting started](/docs/getting-started), then read the
[architecture](/docs/architecture) and [security model](/docs/security) before
writing a driver or moving funds. Package references are linked to the exact
submodule commits in this checkout.

NMDK is currently a development release. The intentionally deferred contract
issue on the [known limitations](/docs/known-limitations) page blocks public
chain and real-value use.
